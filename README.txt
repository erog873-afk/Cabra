GIFT APEX — КЕЙСЫ / АДМИН MINI APP

ENV Render:
BOT_TOKEN=токен бота
WEBHOOK_SECRET=твоя текущая секретная строка
ADMIN_IDS=Telegram ID администратора
PORT=10000

Админка: /admin.html

В админке раздел называется «Кейсы» без иконки. Иконки самих кейсов и подарков остаются и редактируются.

server.js сохраняет существующий баланс/пополнение и добавляет:
GET /api/cases
PUT /api/admin/cases

Основной Mini App обновляет список кейсов каждые 2 секунды.
db.json создаётся/обновляется рядом с server.js. Для Render нужен Persistent Disk, если данные должны переживать перезапуск/деплой.
